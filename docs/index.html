About the model and assumptions

The model uses six stations common to all five supplied services. A three-state Markov chain (low, moderate, high disruption) controls illustrative extra disturbances. Running-time noise, exponential dwell-time variation, the transition matrix, and the 3-minute minimum departure headway are assumptions—not measured parameters for these specific trains.

The Sri Lanka Railways Administration Report 2023 and the Auditor General's Annual Report 2024 provide system-wide punctuality context. They do not provide the train-by-train histories needed to estimate route-specific Markov transitions or dwell-time distributions. Therefore, the simulation should not be described as calibrated to actual Maradana–Panadura delays.

Notebook reference: in the Colab notebook, the deterministic limiting-case verification checks that the five supplied timetable rows are reproduced when stochastic disturbances, initial delay, recovery buffer and headway effects are disabled. This page displays the same scheduled baseline reference and allows assumption-based scenarios to be explored.
